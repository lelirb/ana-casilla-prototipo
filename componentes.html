Casilla Electrónica · Autoridad Nacional del Agua

Sistema de diseño ANA · Componentes

Cada componente con sus estados y el código listo para copiar. Es el mismo HTML y la misma hoja (ana.css) del prototipo; en Figma, el archivo «ANA Design System».

Cómo usar

  1. Copia ana.css, app.js, iconos.svg e ilustraciones.svg del repositorio.
  2. Enlaza la hoja: <link rel="stylesheet" href="ana.css"> y, al final del body, <script src="app.js"></script>.
  3. Pega el contenido de iconos.svg (y de ilustraciones.svg si usas estados vacíos) una sola vez, al inicio del body, dentro de <div class="sprite" aria-hidden="true">. Así los íconos se usan con <use href="#nombre"> y funcionan también abriendo el archivo sin servidor.
  4. Copia el código de cada componente. Los componentes usan solo tokens semánticos (var(--texto-accion), etc.); no pongas colores sueltos.

Todo está hecho para cumplir WCAG 2.2 nivel AA. Las notas de accesibilidad de cada componente dicen qué no se debe quitar.

Íconos

40 íconos de 24 × 24 con trazo de 2, en iconos.svg. Toman el color del texto (currentColor). Son decorativos: si un botón solo tiene ícono, el botón lleva aria-label. Tamaños: icono (20), icono--16, icono--14. Toca uno para copiar su código.

Ilustraciones

8 ilustraciones de 120 × 120 para estados vacíos y errores, en ilustraciones.svg. Sus colores salen de ana.css (.ilu-t, .ilu-r, .ilu-b, .ilu-p).

Acciones

Botón

En Figma: Botón

Primario para la acción principal de la pantalla (una sola). Secundario para acciones alternativas. Terciario y Enlace para acciones de bajo peso. Alto mínimo 44 px.

Accesibilidad: Usa <button> para acciones y <a> para ir a otra página. Si el botón solo tiene ícono, lleva aria-label. Deshabilitado: atributo disabled (no solo color).

Campos

Campo de texto

En Figma: Campo de texto

Etiqueta arriba, siempre visible. La ayuda va debajo; el error reemplaza el borde y se describe con texto e ícono.

Accesibilidad: La etiqueta usa for. La ayuda y el error se enlazan con aria-describedby; el campo con error lleva aria-invalid="true". Los opcionales se marcan con texto «(opcional)».

Contraseña con medidor

En Figma: Campo de contraseña · Medidor de contraseña

Botón para mostrar u ocultar. El medidor indica la seguridad con barras y con texto, y lista los requisitos.

Accesibilidad: El botón de ver contraseña cambia su aria-label. El nivel del medidor también está en texto, no solo en color (1.4.1).

Escribiendo

Seguridad: fuerte. Cumple 4 de 4 requisitos.

  • Al menos 8 caracteres, cumplido
  • Una mayúscula y una minúscula, cumplido
  • Un número, cumplido
  • Un símbolo, como # o @, cumplido

Combo con buscador

En Figma: Combo con buscador

Para listas largas, como los 46 procedimientos TUPA. Escribir filtra; las opciones pueden ir en grupos.

Accesibilidad: Patrón combobox de ARIA 1.2. Se escribe un <select> normal con data-combo-auto (o se llama crearCombo(select) en app.js) y el script arma el combo: flechas recorren, Enter elige, Escape cierra y la cantidad de resultados se anuncia.

Funcional (prueba escribir «licencia»)

Código de partida: el <select>. El combo lo arma app.js.
